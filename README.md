## What it is ?
a text-based maths_puzzle, a code of c++ that makes random basic calculation problems , and counts score.

## what it dose ?
1)it asks you the number of questions you want and it generates random numbers and asks you random type of question 
2)(from basic +,-,*,/) made with random numbers.
3)counts number of questions and correct questions.
4)states the final score at the end.

## How did i made it ?
i used rand() function with time to get random numbers every time , used basic loops to repeat the question formation
and input verifying .
used conditions to block the unwanted format (like 0 in fraction )

## how did i run it 
in folder:
to compile it : g++ math_puzzle.cpp -o math_puzzle .
to run it : ./math_puzzle .
